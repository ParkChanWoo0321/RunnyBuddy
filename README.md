# 🏃 Runny Buddy

**Runny Buddy**는 러닝을 좋아하는 사람들이 자신의 러닝 기록과 경험을 공유하고,  
다른 러너들과 소통할 수 있는 **러닝 커뮤니티 서비스**입니다.

회원가입과 로그인을 통해 서비스를 이용할 수 있으며,  
자신의 러닝 기록, 러닝 장소, 러닝 후기 등을 게시글로 작성하여 다른 사용자들과 공유할 수 있습니다.

---

## 📌 프로젝트 소개

Runny Buddy는 단순히 러닝 기록만 남기는 서비스가 아니라,  
러닝을 함께 즐기는 사람들과 경험을 나누고 반응을 주고받으며  
지속적으로 동기부여를 얻을 수 있도록 만든 커뮤니티 플랫폼입니다.

사용자는 자신의 러닝 경험을 글로 남길 수 있고,  
다른 사용자의 게시글에 좋아요를 누르거나 댓글을 작성하고,  
스크랩 기능을 통해 관심 있는 글을 저장할 수 있습니다.

또한 누군가 내 게시글에 좋아요를 누르거나 댓글을 남기거나 스크랩하면  
**실시간 알림**을 받아 즉시 확인할 수 있습니다.

---

## ✨ 주요 기능

### 1. 회원가입 / 로그인
- 회원가입을 통해 서비스 계정을 생성
- 로그인 후 커뮤니티 기능 이용 가능

### 2. 러닝 기록 공유
- 내가 어디서 뛰었는지
- 어떤 러닝을 했는지
- 러닝을 하며 느낀 점이나 후기
- 러닝 관련 경험을 게시글 형태로 작성 및 공유

### 3. 게시글 검색
- 원하는 게시글을 검색하여 빠르게 탐색 가능

### 4. 좋아요
- 다른 사용자의 게시글에 좋아요를 눌러 공감 표현 가능

### 5. 스크랩
- 마음에 드는 게시글을 스크랩하여 저장 가능

### 6. 댓글
- 게시글에 댓글을 남기며 사용자 간 소통 가능

### 7. 실시간 알림
- 내 게시글에 좋아요가 눌렸을 때
- 내 게시글에 댓글이 달렸을 때
- 내 게시글이 스크랩되었을 때  
→ 실시간으로 알림 수신 가능

---

## 🔥 러너 등급 시스템

Runny Buddy는 **내가 작성한 게시글들의 누적 좋아요 수**를 기준으로  
러너 등급이 올라가는 시스템을 제공합니다.

| 등급 | 누적 좋아요 수 |
|------|----------------|
| 초보러너 | 0 이상 |
| 열정러너 | 10 이상 |
| 스마트러너 | 30 이상 |
| 마스터러너 | 50 이상 |
| 레전드러너 | 100 이상 |

이 등급 시스템을 통해 사용자들은 더 활발하게 기록을 공유하고  
커뮤니티 활동에 참여할 수 있습니다.

---

## 👥 서비스 흐름

1. 회원가입을 한다.
2. 로그인 후 서비스에 접속한다.
3. 자신의 러닝 기록과 경험을 게시글로 작성한다.
4. 다른 사용자의 게시글을 검색하고 확인한다.
5. 좋아요, 댓글, 스크랩으로 소통한다.
6. 내 게시글에 반응이 생기면 실시간 알림을 받는다.
7. 누적 좋아요 수에 따라 러너 등급이 올라간다.

## 🧰 기술 스택

* Java 17
* Spring Boot 3.x
* Spring Security + JWT
* JPA (Hibernate)
* MySQL
* SSE (Server-Sent Events)
* MultipartFile (이미지 업로드)
* Gradle

---

## 🔐 인증 및 보안

* JWT 기반 인증 (AccessToken + RefreshToken)
* 소셜 로그인 성공 시 JWT 자동 발급
* 인증 불필요 경로: `/auth/**`, `/oauth2/**`, `/error`
* 모든 인증 요청에 `Authorization: Bearer {accessToken}` 필요

## 📋 기능 요약

| 분류           | 기능                                                              |
| ------------ | --------------------------------------------------------------- |
| Auth         | 회원가입, 로그인, 로그아웃, 소셜 로그인, 닉네임 중복확인, 프로필 변경, 내 정보 조회/수정, 비밀번호 재설정 |
| Post         | 게시글 생성/수정/삭제/조회, 이미지 첨부, 태그 검색, 내가 쓴 글 조회                       |
| Comment      | 댓글 작성/수정/삭제, 대댓글 작성/수정/삭제                                       |
| Like         | 게시글 좋아요 토글, 좋아요 수 조회, 내가 받은 총 좋아요 수, 내가 쓴 글 별 좋아요 수 조회, 좋아요 취소  |
| Scrap        | 스크랩 토글, 스크랩한 게시글 조회, 스크랩 취소                                     |
| Notification | SSE 알림 구독, 전체 알림 조회                                             |
| Badge        | 사용자 뱃지 조회 (좋아요 수 기준 자동 지급)                                      |
